## 一、设计概述

### 1.1 风格定位

整体视觉语言对标 **Opal iOS**：**暗黑沉浸 + 宝石发光 + 极简专注**。

- **关键词**：Dark Mode、矿物/宝石隐喻、发光渐变、毛玻璃、胶囊化指标。
- **情绪目标**：安静、神秘、克制——让用户打开 App 就自然进入"专注仪式感"，而不是被花花绿绿的界面分散注意力。
- **产品隐喻**：沿用"宝石/水晶"意象——每完成一个番茄钟 = 挖到/点亮一颗宝石，专注时长积累 = 宝石能量增强。

### 1.2 设计原则

| 原则 | 说明 |
| --- | --- |
| 内容即主角 | 计时数字、分数是唯一的视觉焦点，大面积留黑衬托 |
| 一屏一焦点 | 每个页面只回答一个问题（还剩多久 / 今天干了啥 / 进度如何） |
| 克制用色 | 95% 黑白灰 + 5% 荧光绿强调，警示色仅在异常时出现 |
| 触达即反馈 | 所有操作（开始/暂停/完成）都有光效、震动或声音反馈 |

## 二、色彩系统

### 2.1 核心色板

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 背景-主 | `#000000` | 页面底色（接近纯黑） |
| 背景-深 | `#0D1410` | 带轻微墨绿调的深色背景/渐变过渡 |
| 卡片 | `rgba(255,255,255,0.06)` + blur | 毛玻璃半透明卡片 |
| 强调-主 | `#7FFFD4` | 荧光薄荷绿：主数字、主按钮、进度 |
| 强调-渐变 | `#7FFFD4 → #FFFFFF` | 发光数字、胶囊描边渐变 |
| 强调-辅 | `#5EE0A0` | 次级高亮、成功状态 |
| 警示 | `#FF6B81` | 粉红/珊瑚色：超时、未达标（如 Opal 的 "Short"） |
| 能量 | `#FF9F45` | 橙色火焰：连续打卡 Streak、能量值 |
| 文字-主 | `#FFFFFF` | 标题、大数字 |
| 文字-次 | `rgba(255,255,255,0.55)` | 说明文字、标签 |
| 文字-弱 | `rgba(255,255,255,0.30)` | 占位、禁用 |

### 2.2 用色规则

1. **发光只给最重要的元素**：当前倒计时/分数用 `box-shadow: 0 0 40px rgba(127,255,212,0.35)` 级别的 glow，页面其余元素不上发光。
2. **语义色固定**：绿=专注/正常，粉红=未达标/中断，橙=连胜/能量，不复用。
3. **深色模式是唯一模式**，不提供浅色主题（保持沉浸感）。

## 三、字体与排版

| 层级 | 字号/字重 | 用途 | 示例 |
| --- | --- | --- | --- |
| Display | 64–96px / Bold / 发光 | 倒计时、Opal Score 级大数字 | `25:00`、`81` |
| H1 | 28px / Bold | 页面大标题 | `Today`、`统计` |
| H2 | 20px / Semibold | 卡片标题、分区标题 | `Gemstones` |
| Body | 16px / Regular | 正文、说明 | 功能描述 |
| Caption | 13px / Medium / 字距+8% | 大写小标签 | `FOCUS HOURS`、`DAY STREAK` |

- 字体栈：`-apple-system, "SF Pro Display", "PingFang SC", sans-serif`。
- 数字统一使用等宽数字特性（`font-variant-numeric: tabular-nums`），避免倒计时跳动抖动。
- 大写英文标签（Caption 层）是 Opal 风格的重要识别点，中文界面可对标签做"小字号 + 加宽字距"处理。

## 四、核心组件规范

### 4.1 胶囊指标（Pill Metric）★ 标志性组件

参考 Opal 的 Sleep / Focus / Rest 三胶囊：

- 形状：全圆角胶囊，1.5px 描边，描边色为强调绿（可渐变）。
- 结构：左侧小图标 + 数字，胶囊下方居中放置 Caption 标签。
- 状态：选中 = 绿色发光描边 + 图标点亮；未选中 = 灰描边低透明度。
- 应用：今日番茄数 / 专注时长 / 连续天数三个指标。

### 4.2 中央主视觉（Hero）

- 计时主页中心：**大号发光倒计时数字**（Display 层级），可外圈套弧形进度环（参考 Opal 的 97 分半弧）。
- 可选增强：番茄完成后中心点亮一颗 3D/渐变宝石，作为收集反馈。

### 4.3 毛玻璃卡片（Glass Card）

- 背景 `rgba(255,255,255,0.06)`，`backdrop-filter: blur(20px)`，圆角 20px。
- 卡片内可嵌套胶囊按钮（如 Opal 的 "Meditate and Sleep" 渐变绿胶囊）。
- 应用：任务卡、休息建议卡、每日目标卡。

### 4.4 按钮

| 类型 | 样式 |
| --- | --- |
| 主按钮（开始/继续） | 胶囊形，绿→白渐变填充或发光描边，深色文字 |
| 次按钮（暂停/跳过） | 胶囊形，透明底 + 白描边 30% |
| 图标按钮（设置/返回） | 44×44 圆形，毛玻璃底 |
| 危险操作（放弃番茄） | 文字按钮，警示粉色，无底色 |

### 4.5 底部导航（Floating Tab Bar）

参考 Opal：**悬浮胶囊式毛玻璃 Tab Bar**，不贴死屏幕底边（留 12px 边距）。

- 3 个 Tab：`主页`（计时）、`任务`、`统计`；设置入口放在主页右上角齿轮，不占 Tab。
- 选中项：图标+文字点亮为白色，其余 55% 白。
- Tab Bar 本体：`rgba(20,20,20,0.7)` + blur，胶囊圆角，外圈细描边。

### 4.6 进度表达

- **分段进度条**：5 段式（Opal 的 Sleep 分段条），用于"今日番茄目标 x/8"。
- **刻度滑条**：AVG 标记样式，用于统计页对比"我的均值 vs 大盘"。
- **环形/弧形进度**：计时器外圈、Score 半弧。

### 4.7 成就与收藏（Gemstones 区）

- 横向滑动卡片列：宝石图 + 名称 + `Owned by xx%` 式文案。
- 映射到番茄钟：成就徽章（首次连续 7 天、单日 10 番茄等）以不同颜色/形态宝石呈现，呼应 F-11 成就功能。

## 五、布局与间距

- **栅格**：iOS 标准，左右安全边距 20pt；卡片间距 12–16pt。
- **纵向节奏**：页面结构自上而下 = `导航区 → Hero 主视觉 → 指标胶囊行 → 内容卡片流 → Tab Bar`，与 Opal 首页同构。
- **圆角体系**：卡片 20px / 胶囊 999px / 小元素 12px，全 App 不出现直角。
- **层级**：背景黑 → 毛玻璃卡片 → 发光强调元素，三层叠加表达深度，不用投影堆砌。

## 六、图标与插画风格

- 图标：线性圆角风格（SF Symbols 气质），1.5–2px 描边，激活态填充发光绿。
- 主题插画：**发光宝石 / 水晶 / 洞穴岩石**质感（参考 Opal 首页宝石与用户页月桂纹章）。可用渐变+噪声纹理模拟，避免廉价 emoji 风格。
- 空状态插画同样使用暗色 + 单点发光，保持氛围一致。

## 七、动效规范

| 场景 | 动效 |
| --- | --- |
| 计时运行 | 数字呼吸式微光（glow 强度随剩余时间渐弱） |
| 番茄完成 | 全屏绿光脉冲 0.6s + 宝石点亮动画 + 轻震动 |
| 进入休息 | 背景从墨绿过渡到更深冷色，节奏放缓 |
| 中断/放弃 | 短促粉红闪光，无庆祝元素 |
| 页面切换 | 淡入 + 8px 上移（200ms, ease-out） |
| 数字滚动 | 统计页数字 count-up（400ms） |

原则：动效服务于"仪式感反馈"，单次时长 ≤ 600ms，不做循环装饰动画。

## 八、页面应用对照

| PRD 页面 | 风格落地要点 |
| --- | --- |
| 计时主页 | 黑色沉浸 + 弧形进度环包裹发光倒计时；下方三胶囊（今日番茄/专注时长/连续天数）；毛玻璃卡片放"当前任务 + 建议休息" |
| 任务页 | 任务列表 = 毛玻璃卡片流；每卡右侧 `3/5 🍅→💎` 进度；新增任务为渐变绿胶囊按钮 |
| 统计页 | 顶部 Score 式大数字（今日专注分）+ 半弧；日/周/月用胶囊 Tab 切换；柱状图用发光绿渐变柱 |
| 设置页 | 设置项 = 毛玻璃卡片行；开关用发光绿 iOS 样式 Switch；数字调节用胶囊 stepper |

## 十、验收清单

- [ ] 全局仅深色主题，背景为近黑色且带轻微墨绿氛围。
- [ ] 发光效果只出现在当前焦点元素（倒计时/主分数/主按钮）。
- [ ] 三个核心指标以胶囊组件呈现，选中态有绿描边发光。
- [ ] 底部导航为悬浮毛玻璃胶囊，含 3 个 Tab。
- [ ] 所有卡片为 20px 圆角毛玻璃，无直角元素。
- [ ] 警示（粉）/能量（橙）/强调（绿）三种语义色未被混用。
- [ ] 倒计时数字使用等宽数字，无抖动。
