# 番茄钟 App 产品需求文档（PRD）

> 文档版本：v1.0
> 创建日期：2026-10-23
> 说明：原始《需求文档.md》为空，本 PRD 基于番茄工作法（Pomodoro Technique）标准方法论与主流专注类 App 通用功能起草，供后续细化。

---

## 一、产品概述

**一句话定义：** 一款基于番茄工作法（25 分钟专注 + 5 分钟休息循环）的轻量级专注计时与任务管理工具，帮助容易分心、难以持续深度工作的用户把大块任务拆成可执行的专注单元，从而提升专注力、降低拖延、量化产出。

**解决的问题：**
- 注意力涣散：刷手机、频繁切换任务导致"假忙"。
- 拖延与启动困难：不知道从哪开始、害怕大任务。
- 产出不可见：一天忙完却说不清专注了多久、完成了什么。
- 休息缺失：连续久坐、忽略休息造成疲劳堆积。

## 二、目标用户

| 用户群体 | 典型场景 | 核心诉求 |
| --- | --- | --- |
| 学生群体（高中生/大学生/考研党） | 备考、写论文、刷题需要长时间专注 | 对抗手机诱惑、把学习拆成可坚持的小段 |
| 知识工作者（程序员/产品/设计/文案） | 需要深度工作（Deep Work）但易被消息打断 | 进入心流、统计真实投入工时 |
| 自由职业者 / 远程办公者 | 缺乏外部考勤约束，时间容易碎片化 | 自我节奏管理、可视化每日产出 |
| 拖延症 / 习惯养成人群 | 想改变"明天再做"的状态 | 用最小行动（一个番茄）突破启动阻力 |
| 效率爱好者 / GTD 实践者 | 已在用任务清单，需要专注执行层 | 任务与计时绑定，闭环"计划→执行→复盘" |

**用户画像（示例）：**
- 阿明，24 岁，后端开发，常因消息打断导致加班；希望通过统计"真实专注时长"向团队证明效率。
- 小鹿，22 岁，考研学生，手机依赖严重；需要强制锁屏式专注 + 每日番茄目标。

## 三、核心功能清单（按优先级 P0 / P1 / P2）

### P0 — 必须有（MVP 核心闭环）
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F-01 | 番茄计时器 | 支持工作 / 短休息 / 长休息三档计时，含开始、暂停、跳过、重置；默认 25 / 5 / 15 分钟，可配置 |
| F-02 | 模式自动切换 | 一个工作番茄结束后自动进入休息，休息结束自动回到工作；切换时有声音 + 系统通知提示 |
| F-03 | 任务绑定 | 为当前番茄选择已有任务或临时新建任务，计时结束自动记录该任务消耗的番茄数 |
| F-04 | 当日基础统计 | 首页展示今日完成番茄数、累计专注时长；任务维度展示各任务已投入番茄 |

### P1 — 重要（提升留存与体验）
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F-05 | 任务管理 | 待办的增 / 删 / 改 / 查，可为任务预估所需番茄数并追踪完成进度 |
| F-06 | 历史统计与趋势 | 按日 / 周 / 月查看完成番茄数、专注时长趋势图表，支持导出 |
| F-07 | 循环规则自定义 | 自定义"每 N 个番茄后长休息"、是否自动开始下一轮、休息是否可跳过 |
| F-08 | 休息与护眼提醒 | 休息到点提醒起身活动；可选护眼模式（如 20-20-20 提示） |

### P2 — 增强 / 差异化（后期迭代）
| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F-09 | 白噪音 / 专注音乐 | 内置雨声、咖啡馆等环境音，或接入音乐播放 |
| F-10 | 多端同步与云存储 | 账号体系 + 云端同步任务与统计数据，支持 Web / 移动端 |
| F-11 | 连续打卡（Streak）与成就 | 每日达成番茄目标获徽章，连续天数激励 |
| F-12 | 每日计划与目标 | 早晨设定当日番茄目标，下班复盘是否达标 |
| F-13 | 浏览器插件 / 桌面端常驻 | 桌面悬浮计时、网页黑名单拦截 distractions |

## 四、关键页面（原型说明，详见配套 HTML）

1. **计时主页**：大号圆形倒计时、模式标签（工作/短休/长休）、任务选择器、开始/暂停/重置按钮、当日统计概览。
2. **任务页**：待办列表、新增任务、预估番茄数、各任务已完成番茄进度。
3. **统计页**：日/周/月切换、完成番茄数柱状图、专注时长趋势、导出入口。
4. **设置页**：工作时长、短休/长休时长、循环规则、声音与通知开关、护眼提醒。

> 配套文件：`番茄钟App-原型.html`（页面线框，不追求美观，仅表达结构与交互）。
