# 一、技术栈总览

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 语言/框架 | **Vue 3 + TypeScript + Vite** | 组合式 API（`<script setup>`），用户熟悉且生态成熟 |
| 状态管理 | **Pinia** | 任务、计时、设置、统计各一个 store；用 localStorage 持久化 |
| 路由 | **Vue Router** | 3 个主视图（主页/任务/统计）+ 设置由主页齿轮进入 |
| 样式 | **CSS 变量 + 组件 scoped CSS** | 设计令牌来自 `DESIGN.md`，不引入 UI 组件库以保留 Opal 定制外观 |
| 计时 | 自研 `useTimer` composable | 基于时间戳精确计时（记录目标结束时间，按 `Date.now()` 计算剩余），非累加 setInterval |
| 持久化 | **localStorage**（键前缀 `pomodoro:`） | MVP 足够；历史会话多时可换 `idb-keyval`，但优先 localStorage |
| 声音 | **Web Audio API** 合成提示音 | 番茄完成"叮"声，无需音频素材文件 |
| 通知 | **Web Notifications API** | 休息/完成系统通知（需用户授权） |
| 图表 | **手写 SVG 柱状图** | 不引第三方图表库，贴合定制视觉 |
| PWA（可选） | `vite-plugin-pwa` | 可安装到桌面/主屏、离线可用、通知；非强制 |
| 测试（可选） | **Vitest** | 单测 `useTimer` 等纯逻辑 |
| 部署 | 静态托管：**Vercel / Netlify / Cloudflare Pages / WorkBuddy cloud-service** | 构建产物 `dist/` 纯静态，无服务端 |

**明确不做**：后端服务、数据库、登录注册、JWT、账号体系、多端云同步。

# 二、通用上下文（所有步骤共享，新会话必读）

## 2.1 产品是什么
基于番茄工作法（25 分钟专注 + 5 分钟休息循环）的轻量专注计时与任务管理工具。用户为易分心/需深度工作者。核心闭环：**建任务（含预估番茄数）→ 主页选任务绑定 → 计时专注 → 完成番茄 → 任务进度+1、统计累加**。

## 2.2 视觉规范（严格照 `design/DESIGN.md` + 高保真原型）
- 暗黑沉浸背景（近黑 `#000` + 墨绿 `#0D1410`），唯一主题，无浅色。
- 主色荧光薄荷绿 `#7FFFD4`；警示粉 `#FF6B81`；能量橙 `#FF9F45`。
- 毛玻璃卡片 `rgba(255,255,255,0.06)` + `blur(20px)`，圆角 20px。
- 胶囊（圆角 999px）指标/按钮；悬浮毛玻璃底部 Tab Bar（3 Tab）。
- 大号发光数字（`text-shadow` 绿光），数字用 `tabular-nums` 防抖动。
- 设计令牌完整列表见 `DESIGN.md` 第九节 CSS 变量，**第一步就要落成 `tokens.css`**。

## 2.3 目录约定（前端工程根目录为 `h5/`）

## 2.4 数据模型（localStorage 契约，全项目统一）
键前缀 `pomodoro:`。

**Task**（任务）
```
{ id:string, name:string, estimate:number(>=1), done:number,
  createdAt:number(epoch ms), archived?:boolean }
```
key：`pomodoro:tasks` → `Task[]`

**PomodoroSession**（每次计时记录，统计用）
```
{ id:string, taskId:string|null, type:'work'|'short'|'long',
  startedAt:number, endedAt:number, plannedMin:number, completed:boolean }
```
key：`pomodoro:sessions` → `PomodoroSession[]`

**Settings**
```
{ workMin:25, shortMin:5, longMin:15, longBreakInterval:4,
  autoStartNext:true, breakEndNotify:true, eyeCare20:false,
  celebrate:true, soundOn:true, whiteNoise:'off' }
```
key：`pomodoro:settings`

**其它**
- `pomodoro:currentTaskId` → `string|null`（主页绑定的当前任务）
- `pomodoro:goal` → `{ dailyPomodoros:number }`（每日目标，默认 8）
- `pomodoro:achievements` → `string[]`（已解锁成就 id）

**派生统计**：今日番茄数 = 当日 `type==='work' && completed` 的 session 数；专注时长 = 其 `plannedMin` 之和；连续天数 = 含今日/昨日向前连续有≥1 完成工作 session 的天数。

## 2.5 编码约定
- TS 严格模式；类型集中在 `types/index.ts`。
- store 暴露 `state + actions`，持久化通过 `useStorage` 在 actions 内写 localStorage（或在 Pinia 订阅中整体持久化）。
- 组件用 `<script setup lang="ts">`；复用 UI 抽成 `components/`。
- 设计令牌只用 `tokens.css` 的变量，禁止硬编码颜色。
